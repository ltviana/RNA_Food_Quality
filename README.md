# RNA_Food_Quality
Modelo de Redes Neurais para identificação e validação da condição de vegetais em tempo real.
Este é um modelo que desenvolvi utilizando o Python para realizar a leitura e validação de diferentes vegetais e suas respectivas condições, através de vídeos ou webcams.
Os vegetais presentes no modelo são: Maçã, Banana, Pimentão, Melão-de-são-caetano, Cenoura, Pepino, Uva, Goiaba, Jujuba (Ziziphus jujuba), Manga, Quiabo, Laranja, Romã, Batata, Morango e Tomate.
Juntamente ao modelo, foi desenvolvido um app que roda o modelo e armazena os dados coletados, gerando dois dashboards, um de volume de frutas e outro financeiro.
O app também conta com tela de login, cadastro de usuários, cadastro de fornecedores e preço por fruta e fornecedor, controle de dados da empresa, etc.
